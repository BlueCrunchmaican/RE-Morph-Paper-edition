RE:Morph (Paper edition)

Kill a mob, become that mob. RE:Morph brings iChun's Morph to Minecraft Java 26.3 as a Paper plugin, with an optional Fabric client mod.

  • The multimorph grid: every main body against every borrowed form. Click a square to report a problem with that pair.
  • The README: what it does and how to install it.
  • The server and player guide.
  • Latest release and the Modrinth page.

An unofficial fan port. It isn't made or endorsed by iChun, who created Morph.
