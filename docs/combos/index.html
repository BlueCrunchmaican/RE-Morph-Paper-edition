Multimorph grid

A multimorph is one morph wearing a piece of another. Every pair is its own small test, and there are 8,190 of them, more than I can check alone. Click a square to report a problem with that pair. It opens a GitHub issue with the pair already filled in. A pair someone has reported turns pink until I've looked at it.

Statuses

    Press a status to hide or show it. Rows are the main body, columns are the borrowed form, and order matters: a cow wearing a frog's tongue and a frog wearing a cow's head are different pairs.

    How to help

    1. Pick a pair, ideally a teal one (needs a look), a gold one (fixed, needs a retest) or a pink one (reported but not checked yet).
    2. Try it in game with the client mod and again without it. The two views don't always agree. Try it both ways round if you can, because main and borrowed are tested separately.
    3. Click its square and press Report this pair. The form says what I count as an issue and asks for your versions and a screenshot.

    A multimorph should look like one creature that could exist: a horse wearing a bat's wings should look like a pegasus. If the borrowed head can't work on a body, its other pieces should come over instead. Not sure it looks right? Report it and say so.

    What the colours mean

    works
    I tried it and it behaved. "Works (sweep)" is a pair I only saw as part of a broad sweep.
    error
    Something is wrong with this pair. I add the bug label to a report once I've seen it.
    needs a look
    It does what it should, but I can't tell if it looks right. I add the needs look label, or you can say so in your report.
    fixed, needs a retest
    A fix is in, but nobody has seen it work on this pair. I add the fixed label. A retest takes a minute or two.
    reported
    An open issue exists for this pair and I haven't gone through it yet.
    unclear
    Tried, but the result wasn't conclusive, or it works as written and it's an open question whether it should.

    When an issue is closed the square goes back to what my last test said. If you can't run scripts, the same grid is in the written list and the CSV.

    This page asks GitHub's public API for the open multimorph issues (a list anyone can read) and nothing else. It sets no cookies and has no trackers. Your theme and zoom are remembered in your own browser only.
